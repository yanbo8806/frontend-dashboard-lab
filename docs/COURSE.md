# 课程地图

适合掌握变量、函数、数组、基本 HTML/CSS 的学习者。主线优先前端知识；GIS、Excel 与 Skill 是进阶材料，可按需选修。以下是同一个项目的分课阅读与练习，不是八套互相复制的应用。

| 课 | 核心问题 | 练习与验收 |
| --- | --- | --- |
| [01 模块化](lessons/01-modules.md) | 入口、编排、组件、纯函数怎么分？ | 给选择器补测试，排序不修改配置 |
| [02 DOM / CSS / SVG](lessons/02-dom-css.md) | 标题、边框、图片如何分层？ | 改一个组件；三种视口不重叠 |
| [03 数据驱动图表](lessons/03-charts.md) | 数字如何变为图例、线、柱、圆环？ | 新增趋势系列，图例与数据同步 |
| [04 配置与状态](lessons/04-state.md) | 草稿、当前数据、本地保存是什么关系？ | 修改占比；非法输入拒绝，刷新保留有效配置 |
| [05 异步与 Worker](lessons/05-async.md) | 如何取消、超时、防止旧请求覆盖？ | 延迟请求取消；Excel 错误可定位 |
| [06 WebGL 与生命周期](lessons/06-webgl.md) | 为什么重绘需要 dispose 和复用？ | 统计更新不重置相机；地图切换不累积画布 |
| [07 AI Skill 与视觉验证](lessons/07-skills.md) | 如何把工作方法做成可复用技能？ | 运行合成负对照；记录真实剩余差异 |
| [08 测试与发布](lessons/08-release.md) | build、测试、安全、部署各证明什么？ | 干净安装验证；准备安全的 Git 提交 |

## 建议教学方式

每课先运行页面观察，再沿源码入口读 2–3 个函数，完成一个小修改，最后用具体测试或界面行为验收。不要先通读所有 GIS 与 Excel 实现。

第一轮只改教学示例中的配置与组件；第二轮再理解网络与图形生命周期。可让学习者提交每课小 PR，解释“状态归谁、输入如何校验、失败如何处理、怎么证明没回归”。

## 综合作业

用自有或获得许可的素材制作另一个城市的展示。先完成业务数据与标签，再替换地图；地图图片锚点和真实经纬度不是同一坐标系，不能只改城市名称。提交代码、配置、至少两项新增测试、运行截图和未完成清单。
