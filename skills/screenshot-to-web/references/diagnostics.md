# 常见偏差的诊断

## 优先级

先看构图和区域边界，再看明显错形与文字重影，然后看字体/基线/色块，最后校准发光和压缩噪声。单看“最大差异簇”会把相邻文本连成大块，忽略更重要的语义错误。

## 图片上重复文字

同一块截图既含标题，又盖上一层 DOM 文本，会让笔画变粗、产生双影。隐藏文本无法满足可编辑要求。优先找干净照片；无原素材时单独处理文字掩码或局部标题底板，并记录损失。不要抹掉整条天空或大面积景物以省事。底图已经有城市标签时，也不能再生成一套偏移的标签。

## 坐标与形状

父元素 border 会改变绝对定位的基准；把装饰框作为独立覆盖层或正确计入盒模型。舞台坐标转父容器坐标只减一次偏移，不能把已经局部化的坐标再放到舞台。裁切图按整数原位摆放，半像素定位会触发重采样。

SVG 的 width/height 和 viewBox 都要看；内容没填满 viewBox 会留下空白，子 SVG 固定宽高也会覆盖容器的尺寸。应按形状选择 preserveAspectRatio，不全局强制拉伸。单色 SVG 不用重复 DOM id；渐变用唯一 id 或统一定义。水平/垂直路径使用 userSpaceOnUse 渐变，避免 objectBoundingBox 的零宽/零高问题。

轮廓先用局部叠加图识别：矩形柱不能写成梯形，实心图标不能替换成线稿，图标在左加右侧两行文字不能描述成三行竖排。代码注释并不构成参考图的证据。

## 字体

核对真实字体名称、加载状态、可见墨迹宽高与基线。候选字体截图或浏览器平台字体信息优于 document.fonts.check 单独判断。先匹配字重、字号、字距、行高与倾斜，再谨慎考虑微小缩放；过度 text-stroke 会糊字。系统字体无法随项目保证跨机一致，有授权字体时内嵌子集并记录许可。

## 判断工具是否可信

PNG 尺寸不一致应报错，不自动拉伸。参数 NaN、负区域、越界裁切、step=0 必须被拒绝。结构检测被请求时，漏掉一个面板或检测失败不能仍返回 PASS。保存前后截图、相同配置、截图哈希和负对照；更新算法后重新计算基线。

MAE、SSIM 是像素观察，不判断内容是否可编辑或图表是否表达正确。不能把 100%-mismatch 命名为“准确率”。颜色启发式得到的差异分类只是线索，不是字体或形状错误的确定诊断。
