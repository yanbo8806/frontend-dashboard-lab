# 国庆出游趋势大屏：本次实证

参考尺寸 1871×841，Vite + 原生 JS/CSS + ECharts。地图为允许使用的位图，照片为裁切素材，标题、面板、KPI 与图表由代码生成。

接手时的实际截图（当前源码重新构建）全局 mismatch 9.7594%、MAE 13.0087、SSIM 0.80216；代码区 mismatch 17.6601%、MAE 24.0139、SSIM 0.6353。旧报告有轻微差异，故先保存本轮基线。

找到并修正的真实问题：

- 页头函数只画一个小梯形，缺少贯穿全宽的轮廓；由连续路径加渐变重建。
- 目的地照片已烧入标题，又叠 DOM 文字；改成局部文字掩码修补，加单层真实文本。原始裁切保留。
- 参考年龄柱为矩形，代码误写成梯形；性别环的位置也偏高。
- SVG 图标有固定宽高且多为错误线稿；改成由容器控制尺寸的实心形状。
- 客源地照片半像素定位并二次裁圆；改为整数原位放置，去掉不存在的定位针。
- 第 3、4 个 KPI 文本整体向右偏约 7px，不能只靠加粗字体修复。
- 原 measure 把相邻亮横线直接当上下边，漏掉 R2 较暗顶边；改为结合切角方向和两端亮度。仍是特定类型检测器。
- viewer 的叠加模式只创建未挂载的图片，差异模式未实现；现通过同一个 Canvas 绘制实际比较模式。

本案例的分区、坐标、颜色或图表估算不能作为下一张图片的默认值。参考图的图例数值和圆弧角度并不完全一致，图表数据只是复刻示意。以上为原项目历史记录，不是当前教学版重跑结果；旧原图与报告没有随教学仓库发布。当前项目请使用自己的参考图和实际生成的报告，不引用本段历史数字作为验收证据。
